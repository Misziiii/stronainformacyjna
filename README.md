# Personal Portfolio Website

A modern, responsive informational website built to showcase my current frontend development tech stack and skills.
This project served as my practical hands-on field to master clean layout techniques, CSS modern features, and native JavaScript animations.

## Live Demo
You can check out the live version here: https://misziiii.github.io/stronainformacyjna/

## Tech Stack & Tools
- HTML5: Semantic structure and SEO-friendly tags
- CSS3: Modern layouts, CSS grid, Flexbox, custom animations, and CSS variables
- JavaScript (Vanilla): DOM manipulation and scroll animations

## Key Features
- Fully Responsive Design: Fluid scaling utilizing the clamp property and Media Queries, making it optimized for mobile, tablet, and desktop views.
- Scroll-driven Animations: Handled efficiently via native JavaScript IntersectionObserver API for great performance and smooth user experience.
- Animated Backdrop: Aesthetic aurora-drift effect utilizing advanced background blend-modes and CSS keyframe animations.
- Accessible Navigation: Functional mobile menu toggle.

## What I Learned
During the development of this project, I focused heavily on self-directed research, utilizing technical documentation and modern AI tools as code-review assistants to help debug and optimize my layouts. 
I successfully mastered:
- Handling asynchronous behaviors with the Intersection Observer API.
- Maintaining a clean and maintainable CSS architecture.
- Improving accessibility, such as using aria-label on navigation buttons.
